ST. ANDREWS ASSIGNMENT GENERATOR — DIRECT DOWNLOADS

Below Print / Save PDF there are direct download options:
- PDF
- PNG
- JPG
- HTML

The filename is generated automatically from:
First Name + Course Name + Front Page

Example:
Mohit's Software Engineering Front Page.pdf
Mohit's Software Engineering Front Page.png

PDF is generated locally in the browser without external libraries.
PNG/JPG are high-resolution A4-sized images.
HTML downloads a clean front-page-only HTML copy.

The website creator credit is hidden from all printed/downloaded front-page files.

Print:
A4
Scale 100%
Margins None
Browser headers/footers OFF
